# AdSense 승인용 페이지 추가 설계

## 배경

현재 사이트(`https://sso0o.github.io/billiards/`)는 당구 경로 도해 도구 하나만 있는 순수 SPA(`index.html`)로, 소개/이용방법/정책 등 텍스트 콘텐츠와 페이지 간 내비게이션이 전혀 없다. 이는 Google AdSense가 흔히 거절하는 "콘텐츠 부족", "탐색 불가" 사유에 해당한다. 이 문서는 승인에 필요한 최소 페이지 세트를 정의한다.

## 범위

- 승인에 필요한 최소 페이지만 추가 (콘텐츠 사이트로의 확장은 범위 밖)
- 라우터 도입 없이 정적 HTML 페이지 추가 (기존 `index.html`은 그대로 도구 페이지로 유지)
- 페이지 문구는 이 문서에 초안으로 작성, 사용자가 검토 후 확정

## 사이트 구조

| 파일 | 배치 위치 | 역할 |
|---|---|---|
| `index.html` | 프로젝트 루트 (기존) | 도구 화면 + 상단 네비 추가 |
| `about.html` | `public/` | 소개 |
| `guide.html` | `public/` | 이용 방법 |
| `privacy.html` | `public/` | 개인정보처리방침 |
| `contact.html` | `public/` | 문의 |

`public/` 아래 파일은 Vite가 별도 설정 없이 빌드 시 `dist/` 루트로 그대로 복사한다 (`public/ads.txt`가 이미 같은 방식으로 처리되고 있음). `vite.config.js`나 `rollupOptions.input` 변경 불필요.

전 페이지 상단에 동일한 네비 바를 둔다:

```html
<nav class="site-nav">
  <a href="index.html">홈</a>
  <a href="about.html">소개</a>
  <a href="guide.html">이용방법</a>
  <a href="privacy.html">개인정보처리방침</a>
  <a href="contact.html">문의</a>
</nav>
```

링크는 상대경로(`about.html` 등, 슬래시 없이)로 작성한다. 현재 `vite.config.js`의 `base` 설정이 비활성화되어 있어 배포 서브경로(`/billiards/`) 여부가 불확실하므로, 절대경로(`/about.html`)를 쓰면 서브경로 배포 시 깨질 수 있다. 모든 산출물이 `dist/` 루트에 나란히 위치하므로 상대경로면 배포 방식과 무관하게 항상 동작한다.

## 스타일

콘텐츠 페이지는 도구용 `src/styles.css`(SVG 테이블 테마)를 가져오지 않는다. 각 정적 페이지에 인라인 `<style>`로 최소 공통 톤만 맞춘다: 다크 배경(`#111513`)·밝은 텍스트(`#eef5f1`), 본문 `max-width: 640px`, 네비 바는 상단 flex row. `index.html`에도 같은 네비 바 스타일을 추가해 톤을 통일한다.

## 페이지별 콘텐츠 초안

### about.html — 소개

```
당구 경로 도해 — 소개

당구 경로 도해는 4구·3쿠션 당구 샷의 예상 경로를 브라우저에서 바로
시각화해주는 무료 웹 도구입니다.

큐볼과 목적구를 테이블 위에 드래그로 배치하고, 두께(두껍게/얇게)와
당점(시계 방향 위치·레벨)을 조절하면 쿠션 반사, 회전(영어),
팔로우/드로우 효과까지 반영한 예상 경로가 즉시 그려집니다. 회원가입이나
설치 없이 브라우저에서 바로 사용할 수 있습니다.

당구를 연습하거나 두께·당점에 따른 공의 움직임을 직관적으로 확인하고
싶은 분들을 위해 만들었습니다.
```

### guide.html — 이용 방법

```
이용 방법

1. 모드 선택
   화면 상단 컨트롤 패널에서 "4구" 또는 "3쿠션" 모드를 선택합니다.

2. 공 배치
   "수구", "제1목적구" 드롭다운으로 공을 고르고, 테이블 위에서 공을
   드래그해 원하는 위치로 옮깁니다.

3. 두께 조절
   두껍게/얇게 옵션으로 큐볼이 목적구를 맞히는 두께를 조절합니다.

4. 당점 선택
   시계식 당점 선택기에서 원하는 위치(시계 방향)와 레벨(강도)을
   클릭해 회전·팔로우/드로우 효과를 지정합니다.

5. 경로 확인
   큐볼 경로(하늘색)와 목적구 경로(파란색), 쿠션 반사 지점이 테이블 위에
   실시간으로 표시됩니다. 경로 중간에 다른 공이 걸리면 경고 메시지가
   나타납니다.
```

## index.html 변경

`<main id="app">` 위에 위와 동일한 `site-nav`를 추가한다. 기존 도구 로직(`src/main.js` 마운트 지점)은 변경하지 않는다.

## 검증

- `npm run build` 실행 후 `dist/`에 `index.html`, `about.html`, `guide.html`, `privacy.html`, `contact.html` 5개 모두 존재하는지 확인.
- `npm run dev`로 로컬 구동 후 브라우저에서 네비 바의 모든 링크를 클릭해 5개 페이지가 정상적으로 열리고 서로 연결되는지 확인.
- 자동화 테스트 대상 아님 (정적 텍스트 페이지, 로직 없음) — 수동 확인으로 충분.
