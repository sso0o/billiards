# FAQ 페이지 추가 설계

## 배경

애드센스 재승인 및 검색 유입 강화를 위해 콘텐츠 페이지를 보강한다. 기존 `about.html`/`guide.html`은 도구 사용법 위주라, 당구 자체에 대한 일반 지식(용어·규칙)을 검색하는 유입을 놓치고 있다. 이 문서는 당구 지식 일반을 다루는 FAQ 페이지를 정의한다.

## 범위

- `public/faq.html` 1개 페이지 추가 (기존 정적 페이지 패턴 그대로 따름)
- 전 페이지 공용 `site-nav`에 FAQ 링크 추가
- `sitemap.xml`에 `faq.html` 항목 추가
- 콘텐츠는 당구 지식 일반(용어·규칙)에 한정, 도구 사용법(guide.html 영역)과 중복하지 않음

## 페이지 구조

`about.html`/`guide.html`과 동일한 골격 재사용: `<meta charset>`, viewport, title(`FAQ - 당구 경로`), description, favicon, GA4 태그, 공통 인라인 `<style>`(다크 배경 `#111513`, 텍스트 `#eef5f1`, `main { max-width: 640px }`), 공통 `site-nav`.

질문/답변은 `<details>/<summary>` 아코디언으로 구현 (JS 불필요, 네이티브 HTML):

```html
<details>
  <summary>질문 텍스트</summary>
  <p>답변 텍스트</p>
</details>
```

## 콘텐츠 (8문항, 확정)

1. **4구(사구)란 무엇인가요?**
   포켓(구멍)이 없는 당구대에서 흰 큐볼 2개(자신의 수구, 상대 수구)와 빨간 목적구 2개, 총 4개의 공으로 진행하는 캐롬 종목입니다. 자신의 수구로 빨간 목적구 두 개를 모두 맞히면 득점합니다.

2. **3쿠션이란 무엇인가요?**
   큐볼이 목적구를 맞히기 전에 쿠션(테이블 가장자리)에 3번 이상 닿아야 득점으로 인정되는 캐롬 종목입니다. 쿠션 반사각을 정교하게 계산해야 해서 4구보다 난도가 높다고 알려져 있습니다.

3. **4구와 3쿠션의 차이는 무엇인가요?**
   4구는 쿠션 접촉 없이도 목적구만 맞히면 득점할 수 있지만, 3쿠션은 반드시 쿠션 3번 이상을 거쳐야 득점합니다. 그래서 3쿠션은 경로 계산과 회전 조절이 훨씬 중요합니다.

4. **당점이란 무엇인가요?**
   큐로 큐볼을 칠 때 맞히는 지점을 뜻합니다. 중심을 치면 회전 없이 직진하고, 중심에서 벗어난 위치를 치면 회전이 걸려 쿠션 반사각이나 목적구를 맞힌 뒤 큐볼의 움직임이 달라집니다.

5. **잉글리시(회전)란 무엇인가요?**
   당점을 공의 중심에서 좌우로 벗어난 위치에 주면 큐볼에 회전이 걸리는데, 이를 '잉글리시'라고 부릅니다. 이 회전은 쿠션에 맞았을 때 반사각을 원래 각도보다 넓히거나 좁히는데, 어느 쪽으로 변하는지는 회전 방향과 진행 방향의 조합(러닝/리버스 잉글리시)에 따라 달라집니다. 3쿠션처럼 쿠션을 여러 번 거쳐야 하는 샷에서 경로를 정교하게 조절하는 핵심 기술입니다.

6. **팔로우샷과 드로우샷의 차이는 무엇인가요?**
   당점을 공의 위쪽에 주면(팔로우) 큐볼이 목적구를 맞힌 뒤에도 앞으로 계속 굴러가고, 아래쪽에 주면(드로우) 맞힌 뒤 큐볼이 뒤로 되돌아옵니다.

7. **두께(겨냥)란 무엇인가요?**
   큐볼이 목적구의 어느 부분을 맞히는지를 나타냅니다. 두껍게 맞힐수록 목적구는 큐볼 진행 방향에 가깝게 뻗어나가고 큐볼은 크게 꺾이며, 얇게 맞힐수록 반대로 목적구가 큰 각도로 꺾이고 큐볼은 방향을 오래 유지합니다.

8. **당구 실력을 빨리 늘리려면 어떻게 해야 하나요?**
   두께와 당점을 하나씩 고정해두고 반복 연습하면서 공의 움직임 패턴을 익히는 것이 도움이 됩니다. 이 도구처럼 경로를 미리 시각화해보고 실제 테이블에서 확인하는 방식도 감을 잡는 데 유용합니다.

## 구조화 데이터

`<head>`에 JSON-LD `FAQPage` 스키마를 삽입해 검색결과 리치 스니펫 노출을 시도한다:

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    { "@type": "Question", "name": "...", "acceptedAnswer": { "@type": "Answer", "text": "..." } }
    // 8개 문항 전체
  ]
}
</script>
```

`name`/`text`는 위 8문항의 질문/답변과 동일한 텍스트를 사용한다(HTML 태그 제외한 순수 텍스트).

## 다른 파일 변경

- `index.html`, `public/about.html`, `public/guide.html`, `public/privacy.html`, `public/contact.html`: `site-nav`에 `<a href="faq.html">FAQ</a>` 추가 (문의 링크 앞, 이용방법 뒤에 배치)
- `public/sitemap.xml`: `<url><loc>https://billiards.sychoi.site/faq.html</loc></url>` 추가

## 검증

- `npm run build` 후 `dist/faq.html` 생성 확인
- `npm run dev`로 로컬 구동, 모든 페이지의 nav에서 FAQ 링크 클릭 시 정상 이동 확인, 아코디언 각 항목 클릭해 펼침/접힘 동작 확인
- JSON-LD는 [Google 리치 결과 테스트](https://search.google.com/test/rich-results)로 배포 후 수동 검증 (자동화 테스트 대상 아님)
- 자동화 테스트 대상 아님 (정적 텍스트 페이지, 로직 없음)
